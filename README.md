# Simple Website ⚡

> "Go Luxury, GoLuxo." — An ultra-fast, modern, accessible, zero-dependency developer website and portfolio template, hosted with GitHub Pages.

**Live site:** [goluxo.github.io/simple-website](https://goluxo.github.io/simple-website/)

---

## ✨ Features

- **Zero Build Step:** Pure semantic HTML5, modern CSS3, and vanilla JavaScript. No `npm`, no bundlers, no build configurations.
- **🌓 Dynamic Theme Switcher:** Smooth Dark & Light mode toggle with automatic system preference detection and `localStorage` persistence.
- **💻 Interactive Developer CLI:** An embedded in-browser terminal emulator supporting interactive commands (`about`, `projects`, `skills`, `theme`, `clear`).
- **♿ Accessibility First:** 100% WCAG AAA/AA compliant color contrast, visible focus rings, ARIA landmarks, and screen-reader safe typography.
- **📱 Fully Responsive:** Adaptive layouts optimized for everything from small mobile screens to 4K displays.
- **⚡ Peak Performance:** Instant load times with inlined vector assets and no external CDN dependencies.

---

## 🚀 Run Locally

No setup required. Just clone and open `index.html` directly in your browser:

```bash
git clone https://github.com/GoLuxo/simple-website.git
cd simple-website
open index.html # or double-click index.html
```
