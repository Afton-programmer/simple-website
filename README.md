# Simple Website

A really simple static website, hosted with GitHub Pages.

**Live site:** https://goluxo.github.io/simple-website/

## Contributing

- Found a bug or have an idea? [Open an issue](https://github.com/GoLuxo/simple-website/issues/new/choose).
- Want to change something yourself? Fork the repo, edit `index.html` or `style.css`, and open a pull request.

## Run locally

Just open `index.html` in a browser. No build step.
